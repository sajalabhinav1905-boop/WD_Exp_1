Experiment 1

Git Version Control & GitHub Workflow

Fundamental branching, staging, committing, and remote tracking workflows.

Step 1

Repository Initialization & Staging

Prepare your workspace and track initial project files.

  • git init — Initializes a new local git repository.
  • git status — Inspects staged, untracked, and modified files.
  • git add . — Stages all working directory changes for commit.
  • git commit -m "feat: initial commit" — Records snapshots into history.
Step 2

Branching & Feature Integration

Work safely in isolated environments before integrating to production.

  • git checkout -b feature/ui — Creates and switches to a dedicated feature branch.
  • git switch main — Navigates back to the default production branch.
  • git merge feature/ui — Incorporates feature branch commits into main.
Step 3

Remote Publishing (GitHub)

Link and synchronize local code with cloud-hosted Git platforms.

  • git remote add origin <URL> — Links your local repository with GitHub.
  • git branch -M main — Sets the primary branch identifier.
  • git push -u origin main — Pushes commits and sets upstream tracking.
